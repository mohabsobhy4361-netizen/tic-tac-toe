# 🎮 Tic-Tac-Toe Game in Python

A simple and interactive **Tic-Tac-Toe game** built with Python and Tkinter. This project is part of my programming learning journey, where I practice Python fundamentals and GUI development.

## ✨ Features

- 🎯 Two-player gameplay
- 🖥️ Graphical User Interface (GUI) using Tkinter
- 🏆 Win detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 Restart game functionality
- ⌨️ Keyboard controls
- 🎨 Dark-themed interface

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** — for the graphical user interface

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python3 --version
```

### Installation

1. Clone the repository:

```bash
git clone https://github.com/mohabsobhy4361-netizen/tic-tac-toe.git
```

2. Navigate to the project directory:

```bash
cd tic-tac-toe
```

3. Run the game:

```bash
python3 tic_tac_toe.py
```

## 🎮 How to Play

1. Two players take turns placing **X** and **O** on the board.
2. The first player to get three marks in a row, column, or diagonal wins.
3. If all cells are filled and nobody wins, the game ends in a draw.
4. Use the restart option to play again.
